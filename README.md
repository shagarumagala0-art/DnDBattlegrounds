# DnD Chat Companion

Fresh-start version of this repository focused on a single feature: an AI-style chat bot interface for tabletop RPG support.

## Current scope

- Chat-first web UI
- In-browser bot responses for encounter, loot, roleplay, and quick-ruling prompts

All previous arena, monster database, and party-management features have been removed from the active app experience.

## Run locally

Open `/home/runner/work/DnDBattlegrounds/DnDBattlegrounds/index.html` in a browser.
